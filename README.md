## ⚡ Importación en 1 clic (OPML)

En vez de copiar URL por URL, importa un archivo y obtén todas las fuentes de una vez, ya organizadas por categorías.

| Archivo | Contenido | Feeds |
|---|---|---:|
| [`opml/rss-es.opml`](opml/rss-es.opml) | Todo en español | 18 |
| [`opml/rss-en.opml`](opml/rss-en.opml) | Todo en inglés | 54 |
| [`opml/rss-todo.opml`](opml/rss-todo.opml) | Español + inglés | 72 |

**Cómo importarlo según tu lector:**

- **Feedly:** *Add content → Import OPML* y sube el archivo.
- **Inoreader:** *Preferences → Import/Export → Import OPML*.
- **FreshRSS:** *Suscripciones → Importar/Exportar → OPML*.
- **NetNewsWire:** *File → Import Subscriptions…* y elige el archivo.
- **[RSS Dashboard](https://lector-rss-next.vercel.app/):** agrega cada fuente con *Agregar* pegando su URL de las tablas.

¿Solo quieres una fuente? Copia su URL de las tablas de abajo: todas están en bloques copiables.

## ✅ Metodología de verificación

> **Verificado el 15/09/2026: 72/72 OK.** Cada URL se comprobó con petición HTTP real (cabecera de navegador, siguiendo redirecciones hasta la URL canónica) y se confirmó como XML válido con artículos (`<item>`/`<entry>`).

La verificación es reproducible: [`tools/verificar.py`](tools/verificar.py) lee los archivos OPML (fuente única de verdad) y comprueba los 72 feeds con la misma metodología. Para correrlo solo necesitas Python, sin dependencias:

```bash
python tools/verificar.py
```

Criterios para que un feed entre o permanezca en la lista:

1. Responde **HTTP 200** con cabecera de navegador estándar.
2. Devuelve **XML válido con al menos un artículo**.
3. Se publica la **URL canónica final** (tras redirecciones).
4. Sin muros anti-bot (403/401/429 permanentes) ni XML vacíos (0 artículos).

## 📝 Historial de cambios

Reemplazos y correcciones acumuladas (las fuentes caídas se sustituyen, no se dejan enlaces muertos):

- Reuters (RSS público descontinuado) → **Al Jazeera** + **DW**.
- Engadget (`rss.xml` con 404) → **Techmeme**.
- VentureBeat (bloqueo anti-bot, 429) → **The Register**.
- PCGamesN (403) → **PC Gamer**.
- Daily Mail (403) → **The Independent**.
- Harvard Business Review (payload ilegible, 0 artículos) → **CNBC**.
- HuffPost (XML válido pero con 0 artículos, RSS descontinuado) → eliminado sin reemplazo directo; alternativas: NPR, DW, Al Jazeera.
- MeriStation (RSS retirado tras migrar a AS.com) → **VidaExtra** + **Eurogamer.es**.
- elEconomista (bloqueo 403 a todos sus feeds) → **La Vanguardia – Economía**.
- Correcciones de URL canónica: BBC Mundo, Aristegui, ComputerHoy, Vandal, 3DJuegos, El Financiero, Yahoo, Macworld, PCWorld, IGN, Game Informer.

## 🤝 Contribuir

¿Conoces un feed que falta o encontraste uno caído? Abre un *issue* o *pull request* con:

1. Nombre del medio, idioma y categoría propuesta.
2. La URL del feed (verifica antes que devuelva XML con artículos).
3. La entrada correspondiente en el archivo OPML de su idioma (`opml/rss-es.opml` o `opml/rss-en.opml`) y, si aplica, en la tabla del README.

Toda URL propuesta debe pasar `python tools/verificar.py` antes de fusionarse.
